# 火入れ名人 (Hiire Meijin)

### 家庭用オーブンから低温調理まで！
### 狙った中心温度までの調理時間を計算するシミュレーター

---

## 概要

火入れ名人は、肉の種類・大きさ・重量・調理器具・初期温度などから、
目標とする**中心温度**まで到達する調理時間を計算するWebアプリです。

家庭用オーブン、トースター、魚焼きグリル、エアフライヤーなどに対応しています。

ブラウザだけで動作し、インストールは不要です。

---

## 主な機能

- 肉の種類を選択
  - 鶏肉
  - 豚肉
  - 牛肉
  - 鴨
  - イノシシ

- 食材サイズを入力
  - 円柱（ロースト等）
  - ブロック

- 重量入力

- 調理器具選択
  - 家庭用オーブン
  - トースター
  - 魚焼きグリル
  - エアフライヤー

- 初期温度設定

- 目標中心温度設定

- 公的殺菌基準との比較表示

- 実測値による器具補正機能

---

## 計算方法

本ソフトは伝熱工学の代表的手法を利用しています。

- Heisler Chart
- Newman Rule
- 一項近似解
- 熱伝導シミュレーション

食品安全については以下の資料を参考にしています。

- USDA FSIS Appendix A
- Anova Sous Vide Pasteurization Guide

---

## 動作環境

ブラウザのみで動作します。

- Chrome
- Edge
- Firefox
- Safari

---

## 使用方法

1. 肉の種類を選択
2. サイズ・重量を入力
3. 調理器具を選択
4. オーブン温度を入力
5. 初期温度を入力
6. 目標中心温度を入力
7. 計算ボタンを押す

---

## 注意事項

本ソフトは家庭調理の参考として作成しています。

肉質、脂肪量、形状、器具の個体差、室温などにより実際の調理時間は変化します。

業務用途・営業用途・医療用途での使用は想定していません。

調理後は必要に応じて温度計で中心温度をご確認ください。
